#GNS3 Networking Projects

## Overview

This repository contains my hands-on networking projects built using **GNS3 (Graphical Network Simulator-3)**. Through these labs, I practised designing network topologies, configuring network devices, assigning IP addresses, and establishing communication between different network segments.

The projects focus on developing a strong understanding of networking fundamentals through practical implementation using **VPCS, Cisco routers, Layer 2 switches, and Layer 3 switches**.

These labs help build the networking knowledge essential for cybersecurity, network troubleshooting, and Security Operations Centre (SOC) analysis.

## Objectives

- Design and implement network topologies in GNS3.
- Configure VPCS end devices and Cisco networking devices.
- Assign IP addresses manually and configure static IP addressing.
- Understand IP addressing, subnetting, and default gateways.
- Configure and test connectivity between network devices.
- Understand the differences between Layer 2 and Layer 3 switches.
- Configure Cisco routers and explore static routing.
- Troubleshoot connectivity issues using networking commands.

## Tools & Technologies

| Tool / Technology | Purpose |
|---|---|
| GNS3 | Network topology design and simulation |
| VPCS | Simulating end-user PCs |
| Cisco Routers | Routing traffic between different networks |
| Layer 2 Switches | Forwarding Ethernet frames within a LAN |
| Layer 3 Switches | Switching and routing between network segments |
| IPv4 | Logical addressing of network devices |
| Static IP Configuration | Manually assigning IP addresses |
| Default Gateway | Forwarding traffic to destinations outside the local subnet |
| Static Routing | Defining routes manually on routers |
| Ping | Testing network connectivity |
| Traceroute | Investigating the path traffic takes through a network |


## Learning Approach

These projects are part of my ongoing practical learning in computer networking and cybersecurity. I use GNS3 to reinforce theoretical concepts through configuration, connectivity testing, and troubleshooting.

The goal is to develop a solid understanding of how networks operate and how that knowledge can be applied to network security and incident investigation.
